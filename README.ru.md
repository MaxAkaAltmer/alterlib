# alterlib

**[English](README.md)** · Русский

Свободная коллекция кода на C++, распространяемая под лицензией MIT.

Это не монолитный фреймворк, а набор слабо связанных утилит и подсистем, которые можно выборочно подключить к существующему проекту и собрать как обычные C++ исходники и заголовки. Всё содержимое живёт в пространстве имён `alt`; GUI-код дополнительно использует `alt::ui`, а код подсистемы вычислений — `alt::compute`.

## Обзор

Alterlib закрывает то, что иначе приходится переписывать в каждом проекте: фиксированной ширины типы, Unicode-строки, рефлексивная модель `object`, контейнеры и структуры данных, работа с файлами, потоками, временем и процессами, изображения и звук, небольшой GUI-стек (GLFW + Dear ImGui с бэкендами OpenGL и Vulkan), хеширование, собственный конвейер архивации/сжатия, маршалинг `object` в XML/Protobuf и диспетчер вычислений OpenCL/CUDA. Подсистемы независимы — подключайте только то, что нужно.

## Подсистемы

- **`crypto/`** — CRC32 (`crypto/crc32.h`) и `alt::cryptoHash` с поддержкой CRC32, MD5 и SHA1 (MD5/SHA1 на базе Crypto++).
- **`compress/`** — Собственный архивный конвейер: арифметический кодек (`arch_arith`), дельта-кодирование (`arch_delta_code`), словарный кодек (`arch_diction`), PPM-модель (`arch_ppm`), склеенные модулями `arch.*` и `arch_prefix.*`.
- **`gui/`** — Минимальный UI-тулкит (`alt::ui::window`, `alt::ui::widget`) поверх GLFW и Dear ImGui, плюс рендер-хелперы: текстуры/шрифты/примитивы OpenGL (`agl_*`) и контекст/текстуры Vulkan (`avk_*`).
- **`compute/`** — Абстракция `alt::compute::computeCluster` с бэкендами OpenCL (`opencl_cluster`) и CUDA (`cuda_cluster`) для распараллеливания задач на устройства.
- **`marshaling/`** — Сериализация/десериализация дерева `alt::object` в XML через tinyxml2 (`aobject_xml`) и в Protobuf через dynamic messages (`aobject_proto`).
- **`scripting/`** — `ALexBase` / `ALexFileNode` — небольшой лексический/скоупинговый движок для встраивания скриптов и структурной конфигурации в модель `alt::object`.

## Структура репозитория

    alterlib/
    ├── crypto/        Хеш-функции (CRC32, alt::cryptoHash)
    ├── compress/      Собственные кодеки сжатия/архивации
    ├── compute/       Слой диспетчеризации OpenCL и CUDA
    ├── gui/           Окна, виджеты, GL/VK текстуры, шрифты, примитивы
    ├── marshaling/    alt::object <-> XML / Protobuf
    ├── scripting/     Лексер и хост скриптов
    ├── external/      Сторонние библиотеки (каждая под своей лицензией)
    └── *.h, *.cpp     Ядро: типы, строки, контейнеры, I/O, потоки, математика, ...

## Сторонние зависимости

Библиотеки, необходимые alterlib, находятся в каталоге `external/`. Каждая сохраняет свою оригинальную лицензию — подробности смотрите в соответствующем подкаталоге.

Напрямую используются исходниками alterlib:

| Библиотека | Где используется |
|---|---|
| [Dear ImGui](https://github.com/ocornut/imgui) | `gui/awindow.*` (с бэкендами GLFW/Vulkan/GL) |
| [tinyxml2](https://github.com/leethomason/tinyxml2) | `marshaling/aobject_xml.*` |
| [Crypto++](https://www.cryptopp.com/) | `crypto/acrypto.*` (MD5, SHA1) |
| [stb](https://github.com/nothings/stb) | `aimage.*` (ввод/вывод изображений), `gui/agl_font.*` (растеризатор TrueType) |
| [miniaudio](https://github.com/mackron/miniaudio) | `asound.*` (включается макросом `ASOUND_ENABLE_MINIAUDIO`) |
| [dirent](https://github.com/tronkko/dirent) | `afile.*` (итерация по каталогам на Windows) |

Также поставляются «на всякий случай» (используются downstream-проектами, но не требуются самому alterlib):

- [Asio](https://think-async.com/Asio/) — асинхронные сети
- [fmt](https://fmt.dev/) — форматирование
- [nlohmann/json](https://json.nlohmann.me/) — JSON
- [clipp](https://github.com/muellan/clipp) — разбор командной строки
- `glext.h` — объявления расширений OpenGL
- [manymouse](https://github.com/jwclulow/manymouse) — ввод с нескольких мышей
- `gamepad`, `GetComPortList` — хелперы для геймпадов и перечисления последовательных портов
- `libnpy` — чтение/запись NumPy `.npy`

Системные зависимости, которые не включены в `external/`: GLFW, заголовки Vulkan SDK и Google Protobuf (`google/protobuf/...`) — предоставьте их через свою платформу при сборке соответствующих подсистем.

## Требования

- Современный компилятор C++. Ядро рассчитано на стандарты C++11/14; отдельные модули (например, `aprocess.h`) проверяют `__cplusplus >= 202002L` / `_MSVC_LANG >= 202002L` и при доступности используют более новые реализации.
- У самого alterlib нет скриптов сборки — ни корневого `CMakeLists.txt`, ни solution-файла. Отдельные сторонние библиотеки предоставляют свои билд-проекты.

## Подключение библиотеки

Alterlib подключается исходниками:

1. Добавьте этот репозиторий в свой проект (submodule, subtree или обычная копия).
2. Добавьте корень репозитория в include-path так, чтобы заголовки разрешались через имена из корня проекта.
3. Компилируйте те файлы `.cpp`, которые реально используете, вместе с собственными исходниками. Заголовки ядра самодостаточны и подтягивают сторонний код только при сборке соответствующего модуля.
4. Для подсистем, которые используют сторонний код, добавьте каталог `external/<lib>/` в include-path (а для библиотек, требующих сборки — например, Crypto++ — соберите или слинкуйте их по их собственной инструкции).

Настраивать нужно только те подсистемы, которые вы реально компилируете.
